** A SIMPLE RAG APPLICATION **

This is a simple but a complete Retrieval Agumented Generation(RAG) AI Agent system that answers user's 
queries from the company documents. The company documents are loaded and store on ChromaDB 
as Embeddings.
To use this code as it is: 
   1. first create your groq api key and use it on the model
   2. Install all the dependencies from the requirements.txt
